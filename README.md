# Pacman Clone

A clone of pacman with 2 player local multiplayer and a randomized map to play on.
## How To Play

Just Download the latest release and run .exe. Note: Windows only.  
Make sure you have a friend to play with, as it's 2 player only (same keyboard).
## Run in Unity

Click on the blue "<>Code" dropdown and click "download zip".
Unzip the folder and open Unity, click add and locate the unzipped folder.
It should open now.
